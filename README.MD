# 🌐 Personal Website

Selamat datang di repository **Personal Website Keira** saya.

Website ini dibuat sebagai media untuk **memperkenalkan diri, menampilkan informasi pribadi, serta membagikan beberapa project yang pernah saya kerjakan**. Website dirancang dengan tampilan yang sederhana, informatif, dan mudah digunakan.

## 🏠 Home

Halaman **Home** merupakan halaman utama website yang berisi pengenalan singkat mengenai diri saya.

Pada halaman ini terdapat:

- Nama
- Deskripsi singkat
- Perkenalan diri
- Navigasi menuju halaman lainnya

## 👤 About

Halaman **About** berisi informasi mengenai diri saya secara lebih lengkap.

Informasi yang ditampilkan meliputi:

- Nama lengkap
- Pendidikan
- Program studi
- Keahlian atau kemampuan
- Minat
- Informasi singkat mengenai diri saya

Halaman ini dibuat untuk memberikan gambaran mengenai latar belakang dan kemampuan yang saya miliki.

## 💻 Project

Halaman **Project** digunakan untuk menampilkan beberapa project yang pernah saya buat selama proses pembelajaran maupun pengembangan kemampuan di bidang teknologi.

Beberapa project dapat berupa:

- Website
- Sistem informasi
- Project pemrograman
- Project database
- Project lainnya

Setiap project dapat dilengkapi dengan deskripsi singkat, teknologi yang digunakan, serta link menuju repository atau hasil project.

## 📞 Contact

Halaman **Contact** digunakan sebagai media untuk menghubungi saya.

Informasi yang dapat dicantumkan antara lain:

- Email
- Instagram
- GitHub
- LinkedIn
- Media sosial lainnya

## 🛠️ Technologies

Website ini dikembangkan menggunakan beberapa teknologi dasar dalam pengembangan web, yaitu:

- **HTML** — untuk membuat struktur halaman website
- **CSS** — untuk mengatur tampilan dan desain website
- **JavaScript** — untuk menambahkan interaksi dan fungsi pada website

## 🚀 Cara Menjalankan Project

1. Clone repository ini ke komputer.

```bash
git clone https://github.com/username/personal-website.git
```

2. Masuk ke folder project.

```bash
cd personal-website
```

3. Buka file `index.html` menggunakan browser.

Website juga dapat dijalankan menggunakan **Live Server** pada Visual Studio Code.

## 🎯 Tujuan Project

Project ini dibuat dengan tujuan untuk:

- Mempraktikkan dasar-dasar pengembangan website.
- Membuat personal website sebagai media pengenalan diri.
- Menampilkan informasi pribadi secara terstruktur.
- Menampilkan project yang pernah dibuat.
- Meningkatkan kemampuan dalam HTML, CSS, dan JavaScript.
- Membuat website yang dapat digunakan sebagai portfolio sederhana.
